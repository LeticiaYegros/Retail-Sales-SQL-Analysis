# Retail Sales SQL Analysis

## Overview

This project analyzes retail sales data containing information about products, customers, and transactions. 
A relational database was designed and implemented in PostgreSQL to support business reporting and sales analysis. SQL queries were developed to evaluate sales performance, customer behaviour, and product trends.

## Objectives

* Develop a relational database for retail sales analysis
* Perform data querying and business reporting using SQL
* Evaluate sales performance across products and customers
* Support decision-making through data-driven insights

## Tools

* PostgreSQL
* pgAdmin 4
* SQL

## Database Structure

The project includes three related tables:

### Products

Stores product details such as category, price, and stock quantity.

### Customers

Contains customer information including contact details.

### Sales

Records sales transactions and links customers with purchased products through foreign keys.

## SQL Topics Covered

SQL Concepts Applied

* Database and table creation
* Data insertion and updates
* Filtering and sorting data
* Aggregate functions
* GROUP BY analysis
* JOIN operations
* Foreign key relationships
* Business reporting queries

## Analysis Performed

Several queries were created to answer business questions, including:

* Which products generate the highest sales?
* How are sales distributed across categories?
* What is the purchase history of individual customers?
* How many products exist within each category?

## Key Findings

* A small number of products generated most of the sales activity.
* Sales performance differed significantly between product categories.
* Customer transaction history provided useful information about purchasing patterns.
* SQL aggregation functions made it possible to quickly summarize business performance.
